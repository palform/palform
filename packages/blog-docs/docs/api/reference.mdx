# Reference

This page contains an automatically generated listing of our API endpoints.
As much of them are documented as possible, and we aim to increase this over time, prioritising the endpoints with the
clearest use cases.
Please don't hesitate to [contact us](../../) if you have any questions.

You can also view the [raw OpenAPI spec file](https://api.palform.app/openapi.json).
Some routes have been filtered out in the list on this page but are still in the spec file.
These routes are related to human user authentication and some dangerous administrative actions that can't
be done via service accounts, such as deleting an organisation or subscribing to a billing plan.
