# Planned features

We're always planning new features, and we welcome suggestions from
our users. If there's something you'd find useful, please tell us in our [feedback form](https://pf.palform.app/feedback) and we'll add it to our list if it fits our project's aims.

These roadmap items are loosely ordered in terms of priority, with
the top one being the most important.

## Full internationalisation

We have countless users already creating non-English forms, but our current interface makes this a bit of an uphill battle.
We want to add a streamlined process for creating multilingual forms, and potentially even making parts of the dashboard
internationalised.

For context, the small amount of Palform-provided text on the form filling interface already support internationalisation and has been translated into German. But more work definitely needs to be done.

## Even more branding customisation

We want to add background colours, patterns, gradients, etc, to make
your forms look nice if you don't have an image to use as a
background.

If there's anything else you want to be able to customise, please
let us know.

## More question types

One of our most requested features is to increase our range of available question types.
We are considering a range of new options.
If you have any suggestions, please let us know!

## Custom domains

We already support custom subdomains of palform.app for paying
customers, but we'd also like to add the ability to host a Palform
completely on your own dedicated domain. This involves some more
complexity (e.g. domain verification), but it's definitely a useful
thing to have.
